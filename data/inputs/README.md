# data/inputs

`statfin_12sz_road_transport_electricity_2012-2025_accessed_2026-06-12.csv` is the Statistics Finland extract deposited with the 2030 study on Zenodo ([doi:10.5281/zenodo.21078010](https://doi.org/10.5281/zenodo.21078010)), reproduced unchanged (MD5 `5be3534790db3345c2fc1e7dd1ae9aa8`, 947 bytes).

`model/model.py` checks the MD5 before using it. If the file is absent, the model falls back to the identical-valued re-extraction in `data/sources/` and says so in `data/calibration.csv`.
